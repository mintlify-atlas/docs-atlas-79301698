<Warning>
  GitHub issues are for confirmed bugs only — not crashes caused by incompatible mods, general troubleshooting, or support questions. For support, use the Discord server: [discord.gg/FVXg7AYR2Q](https://discord.gg/FVXg7AYR2Q)
</Warning>

## Before you open an issue

<Steps>
  <Step title="Write in English">
    All bug reports must be written in English so that maintainers and other contributors can understand and act on them.
  </Step>
  <Step title="Check existing issues">
    Search the [issue tracker](https://github.com/xCollateral/VulkanMod/issues) to see if the bug has already been reported. If it has, add any additional information as a comment on the existing issue rather than opening a duplicate.
  </Step>
  <Step title="Check the incompatible mods list">
    Confirm that none of the mods in your instance appear on the [incompatible mods list](https://github.com/xCollateral/VulkanMod/wiki/Incompatible-mods). Issues caused by incompatible mods will be closed without investigation.
  </Step>
</Steps>

## What to include in your report

<Steps>
  <Step title="Describe the bug">
    Write a clear, concise description of what the bug is. Attach screenshots if they help illustrate the problem.
  </Step>
  <Step title="Provide steps to reproduce">
    List the exact steps needed to reproduce the behavior, for example:

    ```text
    1. Launch Minecraft with VulkanMod installed.
    2. Load a world.
    3. Open the video settings menu.
    4. ...
    ```

    If the issue is not consistently reproducible, describe the conditions under which it occurs.
  </Step>
  <Step title="Attach your log file">
    Include the `latest.log` file from your Minecraft instance. You can find it at:

    ```text
    .minecraft/logs/latest.log
    ```

    Drag and drop the file directly into the GitHub issue form. Do not paste raw log text as it is too large to read inline.
  </Step>
</Steps>

## Submit your report

Once you have gathered the information above, open a new issue at:

[github.com/xCollateral/VulkanMod/issues](https://github.com/xCollateral/VulkanMod/issues)

Select the **Bug Report** template and fill in all required fields.
