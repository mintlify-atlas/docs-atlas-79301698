VulkanMod is a Fabric mod for Minecraft Java Edition that completely replaces the default OpenGL 3.2 renderer with a custom Vulkan 1.2 rendering engine. It is not a simple translation layer — it is a full rewrite of Minecraft's internal renderer built from the ground up using the Vulkan API.

## Why VulkanMod?

Minecraft's renderer dates back to OpenGL 3.2 — an API from 2009. VulkanMod modernizes this by adopting Vulkan 1.2, a low-overhead, explicit graphics API that unlocks:

- **Reduced CPU overhead** — Vulkan's explicit command model moves work off the CPU and reduces driver-side synchronization
- **Indirect draw** — GPU-driven rendering lets the graphics card determine what to draw, bypassing CPU bottlenecks
- **Modern GPU features** — access to capabilities not available or poorly supported in OpenGL
- **Native platform support** — first-class Wayland support on Linux, MoltenVK on macOS

## Quick start

<Steps>
  <Step title="Install Fabric Loader">
    Download and run the [Fabric installer](https://fabricmc.net/use/installer/) for your Minecraft version. VulkanMod targets **Minecraft 1.21.9 / 1.21.10**.
  </Step>
  <Step title="Download VulkanMod">
    Grab the latest `VulkanMod_*.jar` from [Modrinth](https://modrinth.com/mod/vulkanmod/versions), [CurseForge](https://www.curseforge.com/minecraft/mc-mods/vulkanmod), or [GitHub Releases](https://github.com/xCollateral/VulkanMod/releases).
  </Step>
  <Step title="Drop the JAR into mods/">
    Place `VulkanMod_*.jar` into your `.minecraft/mods` folder.
  </Step>
  <Step title="Launch Minecraft">
    Start the Fabric profile in the Minecraft Launcher. VulkanMod loads automatically — no additional configuration required.
  </Step>
</Steps>

<Note>
VulkanMod is a **client-side** mod only. It does not need to be installed on servers.
</Note>
